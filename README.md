# 巨兽之城

2–6 人的掷骰对抗网页桌游：每人一只怪兽，掷骰子攒分、攒能量、打人，抢占城心。先到 20 分，或者把别的怪兽全打倒就赢。线上地址 gulugagame.com/kaiju（服务端口 3026，网页开发端口 5297）。

## 怎么玩（用自己的话）

- **目标**：先到 20 分（要撑过这个回合），或者成为最后一只还站着的怪兽。
- **掷骰**：每回合掷 6 颗骰子，可以挑几颗留着、其余重掷，最多重掷两次（留着的也可以拿起来重掷）。
- **六种骰面**：
  - 1 / 2 / 3：三个一样才得分，三个 n 得 n 分，每多一个同样的 +1（四个 3 是 4 分）。
  - 闪电：一颗 1 能量，能攒着。
  - 心：一颗回 1 血，上限 10；**在城里不能用心回血**。
  - 爪：打人。在城外打城里的怪兽，在城里打城外的**所有**怪兽。
- **城心**：结算完骰子，城心空着就必须进去（+1 分）；回合开始还在城心 +2 分。但城里的怪兽挨所有人的打，也不能用心回血。
- **让位**：在城里被爪打中后（伤害照吃），可以让位，把城心让给打你的怪兽。
- **买卡**：能量买公开的 3 张超能力卡（左上角是价格）。「保留」卡一直生效，「一次性」卡立刻生效然后弃掉；花 2 能量可以把 3 张全换掉。
- **5–6 人**：多一个位置「港湾」，城心有人、港湾空着时结算完要进港湾。城心和港湾都算「在城里」，两只城里的怪兽互不打。场上只剩 4 只及以下时港湾关闭。
- **2 人局**：进城、回合开始在城里给 1 能量，不给分。

## 超时

| 步骤 | 限时 | 超时怎么办 |
|---|---|---|
| 掷骰（每次掷完重新计时） | 40 秒 | 还没掷就掷一次，然后不重掷直接结算 |
| 让位 | 20 秒 | 留下 |
| 双翼（挨打时） | 10 秒 | 不用 |
| 买牌（每买一张重新计时） | 30 秒 | 直接结束回合 |

计时按 `turn:step` 一个 key：只在换人或换步骤时变；快速治疗是轮外操作，不改 step，不会重置别人的倒计时。

## 本地运行

```bash
npm install
npm run dev          # 服务端 3026 + 网页 5297（WEB_PORT / SERVER_PORT 可以改）
npm test             # 规则引擎 + 服务器测试
npm run typecheck
BASE_PATH=/kaiju/ npm run build
```

一个人测：`node scripts/test-bot.mjs host 4 3`（机器人建 4 人房、拉 3 个机器人，等你加入凑满后开局）；`node scripts/test-bot.mjs join <房间码>` 加入别人的房间。`BOT_DELAY_MS`、`BOT_IDLE=1`、`BOT_REMATCH=1` 见文件开头。

抓包：`node scripts/spy.mjs [人数]` 连上 dev 服务器打完一局，检查发给另一位玩家的数据里没有牌堆、种子、随机数状态、动作序列，牌堆顶（实验室出品）只发给正在买牌的主人。

## 对外接口（packages/game）

- `createGame(players: {id, name, monster?}[], seed?, overrides?) → GameState`
- `apply(state, playerId, command, rng) → {state, events}`：纯函数，不改输入；`applyCommand(state, playerId, command)` 用 state 里的随机数状态。
- `actorId(state)`：现在该谁操作（被问让位、双翼时是被问的人）。
- `legalActions(state, playerId)`：当前能做的动作（留骰组合只列代表性的几种）。
- `timeoutTurn(state)`、`stepTimeoutMs(state)`：超时处理和这一步的限时。
- `redactGameForViewer(state, viewerId)`：下发前去掉牌堆、种子、随机数状态、动作序列；实验室出品的牌堆顶只给正在买牌的主人。
- `scriptedRng(faces, seed?)`：按剧本出骰面的随机数（教程、预览、测试用）。

### 预览局面工厂

```ts
import { buildState, scene, SCENE_NAMES, applyScripted } from "@kaiju/game";

// 按名字造：start / start2 / start6 / rolled / lastRoll / resolveEnter / yield / yieldJets / wings / buy / buyRich /
// buyLab / buyTentacles / mimicChoice / cityFull6 / poisoned / zeroDice / offline / timeout / eliminated / bigTable /
// endVp / endTie / endLast / endAllDead
const yieldPrompt = scene("yield");

// 按参数造任意精确局面（玩家 id 是 p1…p6）
const state = buildState({
  players: 4,             // 人数
  current: 1,             // 谁的回合（座位）
  p: { 0: { location: "city", life: 4, vp: 15, energy: 3, cards: ["wings"], poison: 1 } },
  market: ["skyscraper", "heal", "frenzy"],
  deckTop: ["energize"],
  dice: ["claw", "claw", "3", "3", "3", "energy"],
  rolls: 2, rollsLeft: 1, // 已掷几次 / 还剩几次
  stage: "roll",          // 或 "buy"
});
// 接着按剧本骰子走一步
const next = applyScripted(state, "p2", { type: "ROLL", keep: [2, 3, 4] }, ["claw", "heart", "3"]);
```

「对手离线」「超时」是房间层面的：预览页里把 `members[i].connected=false`、`turnRemainingMs` 改掉即可；`scene("timeout")` 给出带 `TurnTimedOut` 事件的局面。

## 人机（「普通」难度）

`packages/game/src/bot.ts`：`botDecision(视角, 我) → { command, reason }`，`botCommand` 只取 command。输入必须是 `redactGameForViewer` 之后的状态（测试里把牌堆换成一碰就报错的代理）。

- 掷骰：三个以上的数字都留；没有三个时留一对 3（或 2，1 只在有美食家 / 冻结时间时）；爪能打到人就留（城外血 ≤4 时不留，怕被打进城）；城外按缺的血留心；能量都留。次数用完还有 3 颗以上没用的骰子时用烟雾 / 心灵感应；剔除弱者、剧情反转、弹性只在能凑出三个时用。
- 只剩 2 只（对决）：多半是比谁先打倒谁——只留三个 3、血少也留爪、加分卡打三折、能量更值钱。
- 让位：吃完伤害还有 ≥7 血留下；≤5 血且下一轮城外可能打出的爪 ≥ 剩余血 −1 就让位；差 ≤2 分赢时赌一把；有喷气式会倒下就让。
- 双翼：会被打倒、或能量 ≥4 且这下 ≥3 点、或血 ≤5 且这下 ≥2 点就用。
- 买牌：每张卡估一个「值几分」（一次性卡按效果、保留卡按剩余回合数折算），减去「价格 / 4」（对决时 / 5），超过 0.3 就买最划算的；买了就到 20 分的一定买；会把自己打死的不买；能量 ≥8 且三张都很差时扫牌。
- 可调参数集中在 `botTuning`。

强度（`npx tsx scripts/sim-kaiju.ts 300`，2026-10-11）：

| 对手 | 人数 | 局数 | 人机胜率 |
|---|---|---|---|
| 随机（A） | 2 | 300 | 100% |
| 基线 B（爪和心优先、凑够就买最便宜、血 ≤5 让位） | 2 | 300 | 73.3% |
| 基线 B ×3 | 4 | 300 | 55.3%（公平 25%），平均名次 1.60 |

全人机自对弈 2–6 人各 300 局：平均 18.9 / 24.4 / 35.7 / 35.4 / 42.1 回合；20 分获胜 8% / 68% / 81% / 82% / 81%，其余是打翻全场，没有全灭；单步耗时 p50 <0.01ms、p99 0.01ms、最坏 0.73ms。
