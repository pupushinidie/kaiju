## 1. 风格

| 项 | 规定 |
|---|---|
| 基调 | 圆滚滚的萌系原创怪兽 + 玩具一样的城市沙盘，放在一张温馨的木桌上；糖果色（薄荷、蜜桃、淡紫、柠檬、珊瑚），全年龄。怪兽是「玩具桌游里的棋子」，不是写实大怪兽 |
| 光照 | 夜间：窗户和台灯的暖黄光 + 靛蓝夜色；白天：晴天柔光、浅蓝天空。物件（怪兽、卡图、图标）统一左上来光：左上高光、右下暗面，地面一块小影子 |
| 描边 | 怪兽、图标、标记、卡框外面 1px 深紫褐描边 `#2a1d33`（不用纯黑）；卡面插图内部可以用选择性描边 |
| 像素密度 | 场景 512×288；城市板 160×128；怪兽 128×128；卡 96×136（插图窗 84×60）；骰子 44×44；图标/标记 32×32。同一屏里所有物件用**同一个倍数**（桌面 2×、手机 1× 为主） |
| 文字 | **所有图里一个字都不要**：卡名、费用、效果、骰子上的 1/2/3、生命/分数/能量数字，全部由界面用字体或代码像素字画。骰子 1/2/3 的面由 `art/dice.py` 用代码像素数字画好（不是模型写的） |
| 不要 | 原版 King of Tokyo 的怪兽、卡图、商标、字体；哥斯拉、金刚、怪兽电力公司、宝可梦等知名角色的样子；真实城市地名和地标；国旗；人物特写 |

## 2. 素材清单

「来源」：**PixelLab** = 出候选、自查后挑定；**代码** = `art/*.py` 画；**代码+PixelLab** = 代码合成 PixelLab 的图。
「夜/日」：**同** = 一张图两种主题都用（透明物件在两种背景上都查过）；**分** = 夜间、白天各一张。

## 3. 界面要用代码叠的东西（图上没有）

- 卡：费用数字（徽章中心）、卡名、效果文字、「保留 / 一次性」字样。
- 骰子：1/2/3 已由 `art/dice.py` 画好（代码像素字，不是模型画的）；保留高亮、重掷动画由界面做。
- 玩家面板：生命、分数、能量数字，标记个数，名字。
- 城心/港湾的名字、「必须进城」提示。

## 4. 生成和导出

- 出图脚本：`art/r1.py`（一个进程、线程池；标准版客户端 `art/pixellab.py`，全站排队）。候选在 `art/out/r1/`。
- 第 2 轮 `art/r2.py`（小立绘、待机动画），第 3 轮 `art/r3.py`（不合格卡图重画、封面）。挑定结果在 `art/picks.py`。
- 骰子和卡框：`art/dice.py`、`art/cards.py`；特效：`art/fx.py`；导出：`art/export.py`（读 `art/picks.py`，写 `art/selection.json`）；核对：`art/check_final.py`、`art/finalize.py report`；示意拼图：`art/mock.py`。
- 账：`art/ledger.jsonl`（正式美术）+ `assets/ledger.jsonl`（开工样张）。
